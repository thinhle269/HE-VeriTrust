# HE-VeriTrust

HE-VeriTrust is a research project on privacy-aware and trust-aware federated
learning for intrusion detection in IoT and IIoT environments.

The project contains Python modules for data preprocessing, client-side
training, federated aggregation, Byzantine attack simulation, encrypted update
processing, trust evaluation, experimental measurement, and result analysis.
Configurations for CIC-IoT-2023 and Edge-IIoTset are included separately from
the implementation.

The source distribution is intended for code reading, experimentation, and
independent analysis. Dataset files and previously generated research results
are not included in this folder.
